# Quinte West Hyperscale Data Center Impact Assessment (v0.6 — Work in Progress)

**Statement of Neutrality:** This research project is **neither for nor against data centers**. Its sole purpose is to inform the public of all available technical, environmental, infrastructure, and regulatory details. Because significant information gaps remain across multiple subject areas, this document is an active **work in progress**.
