# Independent Electricity System Operator (IESO)

**Role**: Provincial grid operator responsible for:
- Managing the Ontario electricity market
- Ensuring grid reliability through demand response programs
- Coordinating generation from diverse energy sources
- Providing transparency via the Data Hub with real-time market data
