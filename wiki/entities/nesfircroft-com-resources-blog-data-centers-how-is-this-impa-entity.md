# Independent Electricity System Operator (IESO)

## Overview
Ontario's independent electricity system operator responsible for grid planning and load forecasting [[1]](https://www.nesfircroft.com/resources/blog/data-centers-how-is-this-impacting-the-energy-mix-for-canada/)

## Key Responsibilities
- Forecasts 400% increase in data center energy demand by 2050 [[1]](https://www.nesfircroft.com/resources/blog/data-centers-how-is-this-impacting-the-energy-mix-for-canada/)
- Manages grid connections for large data center projects [[1]](https://www.nesfircroft.com/resources/blog/data-centers-how-is-this-impacting-the-energy-mix-for-canada/)
