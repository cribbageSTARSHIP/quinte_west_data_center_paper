# Valuation Methodology for Standard Industrial Properties in Ontario

This page outlines the methodology used by the Municipal Property Assessment Corporation (MPAC) for valuing standard industrial properties in Ontario. The process involves assessing property values every four years, with the latest update reflecting the valuation date of January 1, 2016.

## Key Components of the Valuation Process

1. **Classification**: Properties are classified under the Industrial Property Class or Commercial Property Class based on their use, as defined by Ontario Regulation 282/98.
2. **Cost Approach**: The cost approach is used to estimate the value of improvements, considering reproduction cost new, physical deterioration, functional obsolescence, and external obsolescence.
3. **Land Valuation**: Land is valued as if it were vacant, using market sales data analysis.

## Depreciation Adjustments

- **Physical Depreciation**: Adjustments are made for physical deterioration, typically a percentage deduction from the replacement cost.
- **Functional Obsolescence**: Adjustments are made for defects, outstanding repairs, and deferred maintenance, either on a component-by-component basis or property-wide.
- **External Obsolescence**: Market-extracted depreciation is used to adjust for external factors affecting property value.

## Example Calculation

- **Reproduction Cost New**: $1,400,000
- **Excess Capital Costs**: -$110,000
- **Replacement Cost New**: $1,290,000
- **Cost to Cure Deferred Maintenance**: -$30,000
- **Physical Depreciation (30%)**: -$378,000
- **Replacement Cost New less Depreciation**: $882,000
- **Additional Functional Obsolescence**: -$72,000
- **External Obsolescence (10%)**: -$81,000
- **Depreciated Value of Improvements**: $729,000
- **Land Value**: $486,000
- **Current Value Estimate**: $1,215,000
