The Manitoba Conservation Data Centre (MBCDC) serves as a critical repository for biodiversity information in Manitoba. It catalogs plant and animal species, assigns conservation status ranks (S1-S3), and maps element occurrences via GIS. This data supports conservation planning and development, with applications for government, industry, and public use. Key functions include setback guidelines for at-risk species and collaboration with developers to minimize ecological impacts. ^[Source: Conservation Data Centre | https://www.gov.mb.ca/nrnd/fish-wildlife/cdc/index.html] [[entities/gov-mb-ca-nrnd-fish-wildlife-cdc-index-html-entity.md]] [[entities/national-wildlife-federation-entity.md]]
